# Perfume - C++ console app

## How program looks
When you run the program you can see caption "Witaj w perfumerii!" (welcome to perfumery). The program can show all perfume which are read from csv file. Then, you can choose gender for which you look for perfume. Next, you can pick whether you are looking for unisex perfume or for concrete gender. Later, you can select your budget. Then, you can choose type of perfume. Finally, you can pick season. After each step you can show all perfume meeting your cryteria.

## Technologies
The program is written completely in C++. It uses among other things two-dimensional arrays, pointers, reference, reading csv file - getline, ifstream, stringstream, substr and erase function, own procedures, if and switch case instructions, for and while loops
